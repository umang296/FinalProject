BIO

Hi, I'm Umang Maharjan, a Bachelor of Computing Systems student at EIT, currently studying in Napier/Hawke's Bay, New Zealand. Outside of my studies, I'm into sneakers, fashion, coffee, and perfume . I enjoy the design and craft side of these as much as the products themselves.

I'm taking this web development course because I want to build a strong foundation in front-end and back-end skills that I can apply to real projects, not just assignments. Design has always interested me, and I like the idea of combining that eye for aesthetics with the technical side of coding. By the end of this course, I hope to walk away with a solid portfolio, more confidence writing clean code, and a better sense of whether web development is a path I want to pursue further in my career.

MY WEB TECHNOLOGIES

My top 5 web technologies

  1. Hosting: I use GitHub Pages to host and share my project files, since it integrates easily with version control and is free for student projects.
  2. Web Design: I design layouts using HTML and CSS, focusing on clean, responsive structures before adding styling details like typography and spacing
  3. Database: I work with MySQL for structuring and querying relational data in back-end projects.
  4. Code Editor: I use Visual Studio Code for most of my development work, thanks to its extensions for live preview, formatting, and Git integration.
  5. Web Frameworks: I'm currently learning JavaScript fundamentals and plan to explore frameworks like React as I progress through the course.
