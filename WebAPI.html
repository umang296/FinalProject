JSON Rules

Important rules that must be adhered to in order to create valid JSON data.

Rule 1: Objects

A JSON object is enclosed in curly braces { } and contains comma-separated key/value pairs.

{ "city": "Auckland", "population": 1650000 }
Rule 2: Keys

Keys must be strings, and must be wrapped in double quotes,single quotes or unquoted keys are not valid.

{ "productName": "Laptop" }
Rule 3: Values

A value can only be a string, number, object, array, boolean, or null. Functions and undefined are not allowed.

{ "available": false, "rating": 4.5 }
Rule 4: Arrays

Arrays are enclosed in square brackets [ ] and hold an ordered list of values.

{ "fruits": ["apple", "banana", "mango"] }
Rule 5: No trailing commas

A comma must never appear after the last value in an object or array,this is a common JSON error.

{ "x": 10, "y": 20 }  ✔
{ "x": 10, "y": 20, }  ✘
Rule 6: No comments

Unlike JavaScript, JSON does not support // or /* */ comments anywhere in the document.

{ "status": "ok" }
// this comment is not allowed
